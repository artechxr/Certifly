🚀 Setup Checklist
1
Spreadsheet & Exact Columns

Rename tab to Attendees. Automation detects these exact columns for fluent operation, Hence the Column and the Column name must be the same as listed - :

Col BFull Name
Col CEmail Address
Col FAttended
Col GQR Status

Note: Do not touch Col F & G. Scanner writes "Yes" in F, and Sync writes "SENT" in G automatically.

2
Certificate Template

Add {{Name}} to your Google Slide.This slide is going to be your template for the certificate. This is case-sensitive. The script swaps this exact tag with the Guest Name.

3
Drive folder for saving certificates

Create a new folder, name it as Event Certificates and save it to your drive, open it and copy the ID mentioned at the end of the url

Note: Keep the Sheet tab name, folder name, column headers and columns the same as provided in order to avoid any kind of error.

4
Vital Public Sharing

Set these files to "Anyone with link" as "Editor" for the automation to work:

✅ Google Sheet (The Database)
✅ Google Slide (The Template)
✅ Drive Folder (The Storage)

5
Copy Your IDs

• Slide ID: Text between /d/ and /edit.
• Folder ID: The final string in your Drive Folder URL.

6
Ready for Launch

Paste IDs, click Sync to send tickets, Scan at the door, and Dispatch certificates to attendees.
